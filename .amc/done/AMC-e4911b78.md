# AMC-e4911b78: Add new Python adapters to CI pytest matrix

## What was built

Extended the CI `python` job in `.github/workflows/ci.yml` to install and run
pytest against the three SDK-specific Python adapters
(`adapters/openai-agents`, `adapters/autogen`, `adapters/crewai`) in addition
to the existing `adapters/python` and `adapters/langchain` jobs. The job
continues to run on the Python 3.10 / 3.11 / 3.12 matrix.

While bringing this up locally, the existing
`pytest adapters/python adapters/langchain` invocation reproduced a pre-existing
duplicate-plugin-registration failure: `agentgit-adapter`'s `pyproject.toml`
already registers `agentgit_adapter.pytest_plugin` under the name
`agentgit_session` via a `pytest11` entry-point, and
`adapters/python/tests/conftest.py` was unconditionally declaring
`pytest_plugins = ["agentgit_adapter.pytest_plugin"]`, which made pluggy raise
`ValueError: Plugin already registered under a different name` and collected
zero tests. Acceptance criterion #3 ("All 95+ Python adapter tests pass in CI
matrix") could not have held without addressing this, so the conftest's
fallback declaration is now guarded — it only declares `pytest_plugins` when
the entry-point is not present (i.e. when `pytest` is run from source without
`pip install agentgit-adapter`). With this guard in place the test suite
collects and passes 98 tests across all five adapter packages.

## Files changed

- `.github/workflows/ci.yml`
  - "Install adapters" step now also `pip install -e`s
    `adapters/openai-agents[dev]`, `adapters/autogen[dev]`, and
    `adapters/crewai[dev]`.
  - "Run pytest" step now also includes those three adapter directories.
- `adapters/python/tests/conftest.py`
  - Guarded the `pytest_plugins = ["agentgit_adapter.pytest_plugin"]` fallback
    behind an `importlib.metadata.entry_points` check, so the conftest no
    longer collides with the package's own `pytest11` entry-point when the
    package is pip-installed (which is what CI does). The fallback is still
    active for users running pytest directly from source.
- `.amc/artifacts/AMC-e4911b78-test-output.txt` (new)
  - Captured stdout/stderr of the ticket's `testCommand` for this cycle.
