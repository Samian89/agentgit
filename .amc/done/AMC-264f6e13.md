# AMC-264f6e13 — Default-safe guards and repository config

## 1. What was built

- `wrapAgentJS` applies the default `ConfirmationGuard` + `SnapshotGuard` chain when `guards` is omitted, supports `guards: false` opt-out, and treats `guards: [...]` as a full override.
- `.agentgit/config.json` guard settings are honored for default guard construction, including `guards.enabled`, confirmation allowlist/denylist/autoConfirm, and snapshot options.
- Python `AgentWrapper` and `wrap_agent` use matching default-on guard semantics, with Python ports of `ConfirmationGuard`, `SnapshotGuard`, guard loading, and registry behavior.
- LangChain `AgentGitCallbackHandler` uses the same default guard implementation and supports `guards=False` opt-out and explicit guard arrays.
- This review cycle hardened the LangChain path so missing or failing default guard dependencies fail closed by blocking tool calls, while `guards=False` still intentionally bypasses guards.
- The combined `pytest adapters/python adapters/langchain` collection issue is fixed; the Python and LangChain test packages have unique/import-safe test modules and pass when collected together.
