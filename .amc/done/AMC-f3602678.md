# AMC-f3602678 — Tauri UI write-side features (completion)

## What was built
- 6 new Tauri IPC commands in Rust (lib.rs): `create_session`, `replay_from_commit`, `export_bundle`, `abandon_session`, `read_config`, `write_config`.
  - `create_session` / `abandon_session`: direct SQLite mutations (status=abandoned supported).
  - `replay_from_commit`: creates new active session + synthetic initial commit object (reuses source tree, writes matching canonical JSON + SHA-256 via new Rust helpers so bundles are valid and import cleanly). Includes `replayedFrom` in commit metadata.
  - `export_bundle`: shells out to `agentgit bundle create <id> -o <path>` (matches existing push pattern).
  - `read_config`/`write_config`: exposed the existing config.json helpers (user/signing/guards.*).
- React UI:
  - "New Session" button + `NewSessionModal` (name + free-form JSON metadata) → creates + auto-selects.
  - Right-click on any StepCard (via new `CommitContextMenu` + Radix) → "Replay from here" (prompts name) / "Export as .agentgit-bundle" (prompts path, shows toast).
  - Session header "…" button + `AbandonSessionModal` (must type exact name to enable confirm) → status=abandoned, filtered from default list, toggle to show.
  - Top-nav "Main / Settings" toggle; `SettingsPanel` loads/saves full config.json (user.*, signing.*, guards.enabled/confirmation/snapshot) via IPC; new wrapped agents pick up guards without restart.
  - Abandoned toggle + toast banner + session list filtering.
- Added `@radix-ui/react-context-menu` and `sha2`+`uuid` (Rust).
- All existing read flows, Vitest tests (21), and Vite build continue to pass unchanged.
