## What was built

Implemented full scope of spec 002-sdk-llm-auto-capture:

- Extended `wrapAgentJS` (now `async`) to detect `agent.llm` (or `WrapOptions.llm.client`) after session setup.
  - Shape detection: `messages?.create` → anthropic; `generateText`/`streamText` → vercel-ai-sdk.
  - `llm: false` short-circuits (no capture).
  - Explicit `{ provider, client? }` supported (client omitted → uses `agent.llm`).
  - Unknown shape: single `console.warn` only when `AGENTGIT_DEBUG=1`.
- Dynamic `await import("@agentgit/adapter-*-sdk")` (non-literal spec to satisfy TS) + try/catch: SDK loads cleanly without adapters; only attempted branch can fail (silent except debug).
- Reuses `wrapAnthropic` / `wrapAI` + their `recorder.recordLlm` hook exactly (no provider logic duplicated in SDK).
- Uses pre-existing `createLlmRecorderBridge(repo, sessionId, getParent, setParent)` to convert `RecordedLlmCall` → `LlmCallInput`, calls `repo.recordLlmCall`, advances `parentHash` so LLM commits interleave with tool commits in linear session history.
- Injected wrapped `llm` back onto proxy target (for `this.llm.*` inside agent's `run`) when auto-detect path.
- Updated `WrapOptions` + new `LlmAutoCaptureOptions` type; exported `createLlmRecorderBridge` and type from index.
- Added `packages/sdk/package.json` peer + dev `workspace:*` deps on the two adapters; extended `pnpm-workspace.yaml` for linking.
- Created hermetic `llm-auto-capture.test.ts` (5 tests, in-memory mocks matching smoke.test shapes, tmp-repo + `repo.log` assertions on `llmCall.provider`/`model`/`usage.totalTokens`/`status`).
- Updated all SDK test files (`wrap.test.ts`, `default-guards.test.ts`, `telemetry.test.ts`) to `await wrapAgentJS(...)` (required for new async signature; existing tool tests unaffected).
- `pnpm --filter @agentgit/sdk api:update` regenerated baseline; `api:check` exits 0.
- All 25 SDK tests pass; ACs met (Anthropic LlmCall, Vercel LlmCall+usage, `llm:false` suppression, tool regression, no adapter crash, dynamic import).

Net: additive surface; `wrapAgentJS(new Agent())` for non-llm agents continues to work (now with `await`).
