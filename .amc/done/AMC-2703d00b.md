## What was built

Mirrored the TS LlmCall support (from AMC-ef730862) in the full Python adapter family:

- **Migration 003** in `agentgit_adapter/migrations.py`: `MIGRATION_003_SQL`, appended to `MIGRATIONS`, `TARGET_VERSION=3`. SQL byte-for-byte parity with TS `003_llm_call.ts`. Updated `test_migrations.py` for 003 match + v3 expectations in all runner/schema tests. New `test_migration_003.py` proves `run_migrations` on v2 fixture advances to v3 and adds `llm_call` column.
- Extended `AgentWrapper._record_commit(..., llm_call=None)` (adapter.py): always emits `"llmCall": llm_call` (null when absent) in canonical commit body (alpha order), adds `llm_call` column to INSERT. Updated identical logic in langchain `handler.py`.
- `AgentWrapper.record_llm_call(...)` public helper: auto-generates UUID id, timestamps, durationMs, status; sets message="LLM: <model>"; delegates to `_record_commit`. Supports fixed-input determinism. Cross-runtime hash test fixture matches TS `Repository.hashObject` / `sha256` + canonical JSON exactly.
- `@agentgit_record_llm` decorator + `openai_chat_extractor` in `decorator.py` (modeled on `@agentgit_record`); exported in `__init__.py`.
- LangChain `AgentGitCallbackHandler`: `on_llm_start` now captures `invocation_params`/`model_name`; `on_llm_end` builds full `LlmCall` dict (model, messages from prompts, usage from `llm_output.token_usage`, joined response text) and persists via `llm_call=`. `_FALLBACK_SCHEMA_SQL` + `_ensure_fallback_schema` include `llm_call` column + v3 schema_version row. New `test_handler_llm_end.py`.
- Framework adapters wired for real LLM data:
  - openai-agents: run_step patch detects `ModelResponse` (model, usage.input/output_tokens, output.content) → `record_llm_call`.
  - autogen: patches `OAIClient.create` + `_generate_oai_reply_from_client` to capture chat.completions request/response + usage → `record_llm_call`.
  - crewai: patched `Task.execute` reads `usage_metrics` (model + usage) post-execute → `record_llm_call` per task.
- New smoke/LLM tests under each adapter (`test_*_llm_capture.py`) asserting ≥1 `LlmCall` with non-empty model (updated fakes to trigger hooks; renamed for pytest collection hygiene).
- All changes keep cross-language canonical-JSON hash identity (verified via node TS replica + Python `_canonical_json` + SHA-256).
