# AMC-974820e7 - Documentation overhaul

## What I built

- Reworked the troubleshooting recovery guidance to avoid mixed stores: corrupt
  indexes now direct users to restore the whole store or rotate the entire
  `.agentgit/` directory before starting fresh.
- Replaced the partial `.agentgit/` pruning recipe with read-only inventory,
  session export, whole-store rotation, and explicit warnings about
  `tree_entries` and `blobs` reachability traps until first-class `agentgit gc`
  exists.
- Clarified that architecture diagrams are plain text rather than Mermaid so
  they render in the current VitePress setup.
- Verified the docs site with `pnpm docs:build`.

## Files changed

- `docs/architecture.md`
- `docs/troubleshooting.md`
- `.amc/done/AMC-974820e7.md`

## APIs, types, or interfaces other tickets may consume

- No runtime APIs, exported types, CLI flags, or persistent schema interfaces
  were changed.
- The docs now describe the intended future `agentgit gc`/`agentgit fsck`
  responsibilities as reachability-aware operations over refs, session heads,
  commits, trees, and blobs.
